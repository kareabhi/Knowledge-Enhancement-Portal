# Knowledge Enhancement Portal

A web-based learning platform to enhance knowledge through courses, quizzes, and study materials.

## Features
- Course Management
- Quiz & Assessment System
- Study Materials & Notes
- User Progress Tracking
- Admin Panel to Manage Users & Content

## Tech Stack
- Backend: Java, Spring Boot, REST API
- Frontend: HTML, CSS, JavaScript
- Database: MySQL
- Tools: Git, GitHub, Postman

## How It Works
1. User registers and logs in
2. Browses courses and study materials
3. Attempts quizzes to test knowledge
4. Tracks progress on dashboard
5. Admin manages courses, quizzes and users
